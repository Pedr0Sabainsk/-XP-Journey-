# XP Journey — apresentação para profissionais XP (15 minutos)

Roteiro sugerido para a página `/projeto`:

1. **Oportunidade (2 min)**: 22,13 milhões apostaram no mês anterior; 56% entre 16 e 39; 21% participaram de educação financeira. O mercado é relevante, não demanda comprovada.
2. **Solução (2 min)**: Academy → Journey → Pass → Premium, CDB separado de benefícios, sem acaso.
3. **Monetização (3 min)**: spread, CAC reduzido, cross-selling, assinatura Premium.
4. **Viabilidade (4 min)**: LTV R$ 166 / CAC meta R$ 60 (2,8x), contraste CAC R$ 300, EBIT anual positivo no ano 3, caixa máximo ≈ R$ 1,3 mi, recuperação acumulada no ano 5.
5. **Riscos (2 min)**: CAC, juros, regulatório, retenção, integração e pool de recompensas.
6. **Piloto e conclusão (2 min)**: validar CAC real, conversão, retenção, saldos, Premium, custos e aprovação jurídica.

Todos os valores financeiros são hipóteses do relatório e requerem validação em piloto. Não confundir o EBIT anual positivo no terceiro ano com a recuperação acumulada no quinto ano.

Os capítulos originais do resumo institucional, as fontes, o ProductTerms e o dashboard interativo permanecem na página, acessíveis como apoio fora do roteiro. Nenhuma rota, `.env`, chave de progresso, função de servidor ou integração foi alterada nesta etapa.

## Iniciar

```powershell
npm install
npm run dev
```

Acesse `http://localhost:5173/projeto` (ou a porta informada pelo Vite).
